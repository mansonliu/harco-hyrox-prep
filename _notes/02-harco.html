帶到 HYROX 的五個結論

  1. Wall Ball 是最困難的一站，弓箭步緊跟在後。兩站比推估合計慢約 3 分鐘，分組排名 70 與 66，是滑雪機以外排名最差的兩站； 你自己的感受也是藥球最難，No Rep 全是高度不夠。HYROX 這兩站量都翻倍，而且排在跑完 7 km 之後。 這是訓練的第一優先，Wall Ball 獨立成第 3 章。
  2. 跑步在 HARCO 場上是相對強項，配速控制得好。Run 7 ÷ Run 2 = 1.03（低於 1.10 代表配速穩）； 跑段總排名從 Run 1 的 647 一路爬到 Run 7 的 208，Run 7 分組 25/121。前段刻意保守、後段沒崩，HYROX 照同樣原則跑。 換算下來 Run 2–8 平均約每公里 4:38（每圈 380 m）。HYROX 每段 1 km、全程兩倍多，8 km 仍是單一項目最大的一塊時間，有氧底子值得投資。
  3. 雪橇在 HARCO 不是弱點，但推雪橇還沒驗證過 152 kg。推雪橇分組 52/121、拉雪橇 65/121，接近中段。 推雪橇當天臨時下修為 126 kg（草皮摩擦大）；HYROX 是 152 kg、4 × 12.5 m，重量多 26 kg、趟數加倍。拉雪橇重量相同、趟數加倍。 訓練初期就要用 152 kg 實測（第 7 章 W5）。
  4. 站內走動約 5 分鐘，是不用體能就能省的時間。HYROX 還要加上轉換區，流程要練到自動化（第 6 章）。
  5. 滑雪機留太多。HYROX 第一站一樣不能衝，但有空間用比 HARCO 稍高的強度做（第 5 章）。
