# HARCO 2026 備賽讀本

**成品：`index.html`** — 左側頁籤式讀本，響應式、暗色模式相容。用瀏覽器開啟即可。
GitHub 的 markdown 渲染看不到排版，請直接下載 `index.html` 開啟。

## 重要提醒

- **跑步是每站間 400 m（全程 3.2 km）**，不是媒體稿寫的 800 m。以官網為準。
- **重量與 Hyrox 完全相同**，只有距離與次數減半。肌力門檻沒有變低。
- 讀本以**男子組 SOLO** 為對象。
- 讀本中的時間是**由 Hyrox 公開資料推估的區間**（約 37–41 分），不是 HARCO 官方預測，也不是統計上的中位完賽時間。HARCO 是首屆賽事，無歷史成績。
- 第 2、3、4 章中標注「HYROX 標準」的規則敘述**不是 HARCO 已公告的規則**，賽前技術說明出來後必須重新核對。
- 官網 FAQ 載明「詳細各關卡規格將於賽前說明文件公告」，公告後需重新核對（見第 8 章待確認清單）。
- **選鞋不能照抄網路上的 HYROX 推薦**——那些推薦建立在 8 km 跑量上；HARCO 跑量只有 0.40 倍，
  站點距離也砍半，但**單次重量與起動峰值沒有下降**，所以抓地與站點穩定的相對權重要適度提高。
- **選鞋章節給的是候選名單不是定案**：先用四項門檻驗現有鞋，通過就不必換。
  實驗室數字（抓地、堆疊、抗扭轉、磨損）都只是代理指標，最終要靠實測與 W6 全程模擬驗證。
- **實例**：使用者手上的 Nike Pegasus 41 濕水泥抓地實測 0.25（本讀本查過最低），
  但在真實雪橇上的體感最好。這不代表數據被推翻——兩者測的不是同一件事；
  正確結論是**「0.25 不足以排除它，體感加零成本使它最值得優先實測」**。
  見第 7 章與 `research/shoe-selection.md`。

```
  codex-hyrox-stations.md     Hyrox 八站技術（Codex 產出）
  codex-sled-deep-dive.md     雪橇兩站專題（Codex 產出）

```

## 重新產生 index.html

```sh
./build.sh
```

改內容只需編輯 `_notes/` 下的 html 分段，再跑 build。
章節（頁籤）由 `<h2 id="...">` 自動切分。
